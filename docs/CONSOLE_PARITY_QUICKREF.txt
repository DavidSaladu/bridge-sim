│                                        │ Custom Ship Functions (250×?)       │

│                Centered                └─────────────────────────────────────┤

- Radar: Circular, short-range (5000u), ghost dots, waypoints, heading indicators

- Docking: Show/hide based on DockingPort component

INTERACTIONS:
- Click+Drag Radar: heading_hint floats, commandTargetRotation() continuously
- Keybinds: helms_turn_left/right (±5°/frame), combat_left/right, combat_boost

PREFERENCES:
- helms_radar_lock: "0"=relative, "1"=north-up

3. ENGINEERING SCREEN
================================================================================

LAYOUT:
┌─────────────────────────────────────────────────────────────────────────────┐
│ Energy/Hull/Shields/Coolant            ┌─────────────────────────────────────┤
│ Self Destruct (240×100) TopLeft        │ Custom Ship Functions               │
│                                        │                                     │
│                                        │                                     │
│  SYSTEM ROWS (each 50h):               ┌──────────────────────┐              │
│  [Selector] [Damage%] [Heat+Arrow] [P] [C]   (horizontal)     │              │
│  [Reactor ]  [███  ] [░░░░↑    ] [===][===]                   │              │
│  [Beam    ]  [█████] [░░░↓     ] [===][===]                   │              │
│  ...etc (9 systems)                    │ Power Slider (270×360) Large       │
│                                        │ Coolant Slider (270×360) Large     │
│  SHIP INTERNAL VIEW (grid of rooms)    │ System Effects (270×400)           │
│  Click room = select system            │                                    │
│                                        └──────────────────────┘
└─────────────────────────────────────────────────────────────────────────────┘

WIDGETS:
- System Selector Buttons: Toggle, select active system
- Damage Bar: 0-100%, green→red gradient, skull icon if damaged
- Heat Bar+Arrow: Blue bar, arrow up (red=heating) or down (blue=cooling)
- Power Slider: 0-3.0 (overclock 300% if reactor), snap {0, 0.5, 1, 1.5, 2, 2.5, 3}
- Coolant Slider: 0-10.0 per system, snap {0, 2.5, 5, 7.5, 10}
- Coolant Remaining: Redistribute pool across systems
- Ship Internal View: Clickable room grid (room_size 48px)

INTERACTIONS:
- Click System Button: Enable Power/Coolant sliders
- Drag Power Slider: commandSetSystemPowerRequest(system, value)
- Drag Coolant Slider: commandSetSystemCoolantRequest(system, value)
- Drag Coolant Remaining: Proportional drain/distribution across all systems

KEYBINDS:
- engineering_select_system[n]: Direct select system 0-9
- engineering_set_power_000/030/050/100/150/200/250/300: Direct hotkeys
- engineering_increase_power/decrease_power: ±0.1/frame
- engineering_increase_coolant/decrease_coolant: ±0.5/frame

SPECIAL:
- If no Reactor/Coolant: power max = 1.0 (100% only)
- Heat visualization: Bar color green (0%) → red (100%), icon flashes if >90%
- Damage visualization: Red bar for health <100%, skull icon, % label

WIDGETS:

- Probe Radar: Hidden, probe-centered, no FOW, manual pan

- Database "DB" button: Auto-navigate to target entry

- science_scan_object: Initiate scan (if delay=0)
- science_select_next_scannable: Cycle to next scannable entity

- NotScanned (gray): "?" + not_scanned description
- FriendOrFoeIdentified (yellow): Faction only
- SimpleScan (green): Type, shields, hull, faction
- FullScan (blue): All + systems + frequencies + description

RESPONSIVE:
- If screen.width < 1435px: Sidebar selector shows, tabs toggle visibility
- If screen.width >= 1435px: Both sidebars visible simultaneously

WIDGETS:
- Radar: Rectangular, long-range, pan manual, friendlys fog of war
- Waypoints: Persistent, draggable, click <1000u to grab
- Option Buttons: Dynamic show/hide based on mode
- Zoom Slider: MIN_ZOOM_DISTANCE to MAX_ZOOM_DISTANCE
- Alert Level Select: Dropdown RED/YELLOW/GREEN

MODES (state machine):
1. TargetSelection (default): Click selects target, display updates
2. WaypointPlacement: Click places waypoint, return to TargetSelection
3. MoveWaypoint: Drag active waypoint, return on release
4. LaunchProbe: Click launches probe at position, return to TargetSelection

INTERACTIONS:
- Click: Depends on mode (target selection, waypoint place, probe launch)
- Drag: Pan radar (TargetSelection) or move waypoint (MoveWaypoint)
- Wheel: Zoom, preserves world coords under cursor

TARGET VALIDITY:
- Checked every frame (onDraw): if target outside friendly short-range, auto-clear
- Waypoints always visible
- Probes tracked by RadarLink component

HACKING:
- Mini-game modal: Simon Says, etc.
- Progress bar + system selector dropdown
- Success = disable target system
- Failure = alert level increase

COMMS (if allow_comms=true):
- Opening: Connection progress bar
- Hailed: Answer/Ignore buttons
- Chat: Text entry + scroll history
- Script: Lua dialog options
- Ships Log: Transaction/event history
